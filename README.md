# StitchCraft

**StitchCraft** is a centralized luxury fashion platform that bridges the gap between customers, expert tailors, and premium fabric suppliers. Designed with a high-end aesthetic, it streamlines the bespoke tailoring process by allowing users to purchase fabrics, discover artisans, and commission custom garments—all in one place.

## 🚀 Overview

The bespoke fashion industry is often fragmented. StitchCraft solves this by creating a unified ecosystem:
* **Customers** can browse premium fabrics, find tailors based on specialization, and manage bookings.
* **Tailors** can showcase portfolios, manage commissions, and build their reputation.
* **Fabric Suppliers** can list inventory for direct purchase.

## ✨ Key Features

### 👤 Customer Portal
* **Bespoke Dashboard:** A luxury landing page to navigate services.
* **Tailor Discovery:** Search and filter tailors by specialization (Bridal, Sherwani, Party Wear, etc.).
* **Fabric Marketplace:** Browse and purchase high-quality fabrics (Velvet, Linen, Cotton, Chiffon).
* **Booking System:** Direct commission requests with description, budget, and deadlines.
* **Order Tracking:** View status of fabric orders and tailoring commissions.

### ✂️ Tailor Portal
* **Portfolio Management:** Upload images of past work.
* **Profile Customization:** Set specializations (e.g., Men's Shalwar Kameez, Bridal Couture).
* **Booking Management:** Accept or decline customer requests.

### 🧵 Fabric Supplier Portal
* **Inventory Management:** List fabrics with detailed specifications (GSM, width, composition).
* **Sales Tracking:** Manage incoming fabric orders.

## 🛠️ Tech Stack

* **Frontend:** React.js, CSS3 (Custom Luxury Theme)
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Authentication:** JWT (JSON Web Tokens)
* **Styling:** Custom CSS with a Gold/Black luxury aesthetic (`Montserrat` & `Playfair Display` typography)
